# Gemi ve Depo Giriş Takip Sistemi

Liman operasyonlarında gemiden depolara yapılan **ürün girişlerini ve araç sevklerini** tek ekrandan takip etmek için geliştirilmiş sade, hızlı ve Türkçe web aracı.

## Özellikler
- 🚢 Gemi bazlı toplam gelecek yük ve anlık depoya giren miktar takibi.
- 🏢 Çoklu depo giriş dağılımları ve ortalama tonaj/araç analizleri.
- 🌙 Gece / Gündüz tema desteği.
- 📂 CSV formatında giriş verilerini yedekleme ve geri yükleme.
- 📱 Tek tıkla WhatsApp giriş raporu metni kopyalama ve Excel'e aktarım.
